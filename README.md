# Login Form using HTML & CSS

## Project Overview

This project is a simple **Login Form** created using **HTML and CSS**.
It demonstrates basic front-end web development concepts such as form structure, input fields, radio buttons, dropdown selection, and CSS styling.

The form collects user details like name, password, gender, phone number, and course selection.

---

## Features

* First Name and Last Name input fields
* Password and Confirm Password fields
* Gender selection using radio buttons
* Phone number input with country code dropdown
* Course selection options (HTML, CSS, SQL, Python, Git, DevOps)
* Submit button
* Basic form styling using CSS
* Centered form layout with Flexbox

---

## Technologies Used

* **HTML** – for creating the structure of the login form
* **CSS** – for styling and layout design

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Double click the **index.html** file.
4. The login form will open in your web browser.
